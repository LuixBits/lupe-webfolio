# Studio artwork

## NixOS

`nix-snowflake.svg` is the **NixOS Logo** by Simon Frankau and Tim Cuthbertson,
maintained by the NixOS Project. It comes from
[NixOS/nixos-artwork](https://github.com/NixOS/nixos-artwork/blob/master/logo/nix-snowflake-colours.svg)
and is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
See the project's [licensing and provenance](https://github.com/NixOS/branding#license-and-attribution).

The local SVG removes editor metadata and simplifies markup, preserving the
original geometry and colours. The paper sticker and caption are styled in
`src/lib/projects/ChannelPlayer.svelte`.

The Projects side-wall print also uses this SVG, unchanged, inside original
frame artwork in `src/lib/projects/overview/WorkshopWallPrint.svelte`.

The studio's keycap tin also uses the same SVG, unchanged.

## Neovim

`neovim-mark.svg` is the Neovim logo by **Jason Long**, licensed under
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). The
[official Neovim site](https://neovim.io/#marketing) supplies and credits the
artwork. This unmodified copy comes from its
[source repository](https://github.com/neovim/neovim.github.io/blob/master/static/logos/neovim-mark.svg).
The studio adds an original frame and keycap illustration around the mark.

## Tux

`tux.svg` comes from [Garrett LeSage's Tux repository](https://github.com/garrett/Tux).
The original Tux illustration is by **Larry Ewing**, made with **The GIMP**;
**Garrett LeSage** redrew it in Inkscape, and **IFo Hancroft** refined and cleaned
it up. The repository releases its vector artwork under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

The local copy removes editor-only metadata and whitespace, preserving the
rendering geometry and colours. Its original copyright metadata remains in the
SVG. The frame, sunset disc and grid behind Tux are original studio artwork.
